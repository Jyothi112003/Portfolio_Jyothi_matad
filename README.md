# Jyothi Matad Portfolio

## Run locally

```bash
npm install
npm run dev
```

## Update the portfolio

- Edit the content in `src/data.js`.
- Replace `public/profile.jpg` with your own photo. Keep the filename, or update the `photo` value in `src/data.js`.
- Replace the placeholder GitHub and LinkedIn URLs in `src/data.js`.
- Add project repository/demo URLs in the `projects` list.
- Put a resume file in `public/` and change `links.resume` when you are ready to link it.

Build for deployment with:

```bash
npm run build
```
